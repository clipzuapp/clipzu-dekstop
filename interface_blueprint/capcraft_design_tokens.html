Interaction rules — what to fix in Qoder
DOActive timeline clip gets 1px colored border (same hue as track, 60% opacity) + slight brightness boost — never a background color change that loses waveform readability
DOCaption strip auto-scrolls horizontally to keep active caption pill centered — active pill gets accent border + tinted bg
DOInspector context switches instantly when selection changes — use CSS transitions on opacity only (150ms), never layout shift
DOWhisper status lives in the toolbar as a persistent indicator (green dot = ready, amber = transcribing with progress %, red = error)
DOAll sliders in inspector update values on input (live preview), debounce actual store writes by 50ms
DON'TNever use modal dialogs mid-edit — export dialog should be a side drawer or bottom sheet, not a blocking overlay that hides the canvas
DON'TDon't show empty states with big centered illustrations — use a single muted text line ("Drag clips here" at 11px) in the timeline empty state
DON'TNever re-render the entire inspector on every playhead tick — tie inspector only to selection state, not playback state
DON'TDon't use system default scrollbars in panels — style them: 4px wide, bg-3 thumb, transparent track, hidden until hover
DON'TDon't block the UI thread during Whisper transcription — show a non-blocking progress bar in the caption track area, app stays responsive
Whisper UX — making it feel fast even when it's slow
DOShow "Transcribing… 34%" with a thin progress bar inside the caption track — not a modal spinner that blocks editing
DOStream caption pills into the strip as each segment completes (nodejs-whisper emits segments) — don't wait for the whole transcription to finish
DOShow estimated time remaining ("~40s left") derived from realtime factor × remaining audio duration
DON'TNever run Whisper on the main thread — always in worker_threads. If app freezes during transcription, this is the cause
