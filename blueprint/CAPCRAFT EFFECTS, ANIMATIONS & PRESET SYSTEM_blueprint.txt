# CAPCRAFT EFFECTS, ANIMATIONS & PRESET SYSTEM

## Production-Grade Architecture Blueprint

### Version 1.0

---

# GOALS

Build a production-grade Effects, Animation, Preset, Keyframe, and Transition system that:

* Does not contaminate Timeline architecture
* Does not create future technical debt
* Does not require future rewrites
* Supports desktop, web, and mobile
* Supports future preset marketplace
* Supports AI-generated effects
* Supports export rendering
* Supports realtime preview
* Supports third-party preset packs
* Supports future plugin architecture

This blueprint assumes the Timeline Engine already exists and remains responsible only for:

```text
Timeline Placement
Timeline Selection
Timeline Interaction
Timeline State
Track Management
Playback State
```

Timeline must NOT own:

```text
Effects
Animations
Transitions
Keyframes
Rendering Logic
Preset Logic
```

---

# CORE ARCHITECTURE

## Design Philosophy

CapCraft should follow:

```text
Asset
↓
Timeline Entity
↓
Modifier Stack
↓
Keyframe Engine
↓
Renderer
↓
Exporter
```

Never:

```text
VideoClip.effect
VideoClip.animation

TextClip.effect
TextClip.animation

Caption.effect
Caption.animation
```

This architecture creates long-term technical debt.

Instead:

```text
Timeline Entity
↓
Modifier Stack
↓
Generic Processing
```

Everything becomes a modifier.

# MODIFIER SYSTEM

## Universal Modifier Model

```typescript
interface Modifier {
  id: string

  type:
    | "effect"
    | "animation"
    | "transition"

  presetId: string

  enabled: boolean

  parameters: Record<string, unknown>

}
```

Modifier is the only attachment system.

# FINAL TARGET

CapCraft architecture after implementation:

```text
Timeline Engine
├── Placement
├── Selection
├── Tracks
└── Playback

Modifier Engine
├── Effects
├── Animations
├── Transitions
└── Presets

Keyframe Engine
├── Curves
├── Easing
└── Evaluation

Render Engine
├── Preview
├── Canvas
└── Composition

Export Engine
├── Render Graph
├── FFmpeg Translation
└── Encoding
```

Each subsystem owns one responsibility.

Each subsystem has one source of truth.

Each subsystem can evolve independently.

This architecture scales from simple caption animations to thousands of effects, preset packs, AI-generated motion templates, and future marketplace distribution without requiring a structural rewrite.
