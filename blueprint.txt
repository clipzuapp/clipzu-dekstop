## Blueprint Final — Semua Keputusan Teknis

### Tech stack (final, no ambiguity)

| Layer | Pilihan | Alasan |
|---|---|---|
| Shell | `electron-vite` + Electron 30 | build tooling terbaik untuk Electron 2024+ |
| UI | React 18 + TypeScript | ecosystem terluas |
| State | Zustand + Immer | ringan, undo/redo via patches |
| Styling | Tailwind CSS | dark theme editor gampang |
| Timeline | custom Canvas renderer | react-dnd untuk drag, Canvas untuk render track |
| Preview | Canvas 2D + `requestAnimationFrame` | tidak butuh WebGL, cukup untuk 1080p preview |
| Video proc | `fluent-ffmpeg` (Node main process) | mature, well-documented |
| Transcription | `nodejs-whisper` (worker_threads) | Whisper.cpp binding, offline |
| Upscale | `realesrgan-ncnn-vulkan` (child_process) | binary 10MB, GPU-accelerated via Vulkan |
| DB/cache | `better-sqlite3` | thumbnail cache + project metadata |
| Packaging | `electron-builder` | auto-update, NSIS installer Windows, DMG macOS |

### Hal yang sering dilupakan (production killers)

`FFmpegService` harus spawn sebagai `child_process`, bukan `execSync`. Kalau blocking, seluruh main process freeze dan app hang.

Whisper harus di `worker_threads` terpisah — model 233MB tidak boleh di-load di main thread karena initial load ~2 detik akan freeze UI.

Timeline zoom state harus terpisah dari project state. Zoom bukan bagian dari file `.ecp`, ini UI-only state jadi jangan di-persist.

Export progress harus di-stream via `ipcMain.emit` tiap 1 detik, bukan nunggu selesai. User harus bisa lihat progress bar realtime.

Thumbnail cache pakai SQLite dengan key `${clipPath}:${frameMs}` → base64 PNG. Tanpa cache ini, setiap kali user scroll timeline akan trigger FFmpeg extract frame dan app terasa lambat.

SRT harus selalu di-export sebagai sidecar file `.srt` bersamaan dengan MP4 — gratis, dan user tidak perlu re-transcribe kalau mau ubah platform.
